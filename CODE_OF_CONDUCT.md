# Code of conduct

People of every experience level are welcome to ask questions, report bugs, and review changes. Explain what you observed, give feedback on the work, and leave room for people to disagree. Use fictional members and wagers when sharing examples.

Harassment, discrimination, threats, and sharing someone’s private information are grounds for moderation. Maintainers may remove content or restrict participation to protect contributors.

Use the menu on the relevant GitHub issue, pull request, or comment to report a concern. Choose **Report to repository admins** when available, or **Report abuse to GitHub Support** for a GitHub policy violation. Keep sensitive details in the report. [GitHub reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

For a software vulnerability, follow the [security policy](SECURITY.md).
