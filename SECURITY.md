# Security

Reports are welcome for the current default branch and the latest release, when available.

If this repository's **Security and quality → Advisories** page shows **Report a vulnerability**, use it to send a private report. If the button is unavailable, open an issue asking a maintainer for a private contact channel. Keep vulnerability details, credentials, and member data out of the public issue.

In your private report, include the affected version or commit, the affected component, the impact, and steps to reproduce with fictional data. If the issue affects a self-hosted instance, also contact its operator.
